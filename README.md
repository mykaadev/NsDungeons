# NsDungeons

Cyclic lock-and-key dungeon generation on a grid, after the method of Unexplored, with an editor preview.

- A seeded generator: start, goal, a major cycle of two arcs, locks, keys, and one-way doors.
- A check that every dungeon can be solved.
- Every step of a generation kept for the editor preview.

Read `Docs/UserGuide.md` to use it, and `Docs/TechDocumentation.md` to change it.
